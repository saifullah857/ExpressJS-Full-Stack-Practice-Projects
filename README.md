## 🚀 Getting Started

### Prerequisites

```bash
node -v    # v14+
npm -v
mongod     # MongoDB running locally
```

### Installation

```bash
# Clone the repository
git clone https://github.com/saifullah857/ExpressJS-Full-Stack-Projects.git

# Navigate into any project folder
cd "Express Major Project"

# Install dependencies
npm install

# Start the server
node app.js
```

> ⚠️ **Note:** Projects using MongoDB require a running local instance or a `.env` file with your `MONGO_URI`. Projects using Cloudinary need `CLOUD_NAME`, `CLOUD_API_KEY`, and `CLOUD_API_SECRET` in `.env`.
